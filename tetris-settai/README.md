# 接待テトリス（ブラウザ版）

プレイヤーにとって一番都合の良いテトリミノを、毎回その場で計算して出してくれるテトリスのブラウザ版です。
HTML と JavaScript だけで動きます。BGM と効果音つき。

## 遊び方

`index.html` をブラウザで開くだけです（ダブルクリックで OK）。サーバーやビルドは要りません。
フォルダごとコピーすれば、どこでも遊べます。そのまま静的サイトとして公開することもできます。

## モード

| モード | ミノの出し方 |
|---|---|
| 接待 | 毎回、一番都合の良いミノを出す |
| ナチュラル接待 | 普段は通常と同じランダム。ピンチになったら気づかれないようにこっそり接待する |
| 通常 | 7種1巡のランダム |
| 鬼Lv1 | 困るミノほど出やすい。良いミノはめったに出ない。NEXT 付き |
| 鬼Lv2 | 困るミノの下位3種からだけ出す。NEXT 付き |
| 鬼Lv3 | 困るミノの下位3種からだけ出す。NEXT なし |

### ナチュラル接待

接待に違和感が出ないよう、普段は通常モードと同じ7種1巡のランダムで進めます。
次のどちらかになったら、裏で接待モードと同じミノ選びに切り替えます。

- 積み上がりが **12段**（20段中）に達した
- 穴（上がふさがった空きマス）が **8個** 以上になった

**高さ8段以下 かつ 穴4個以下** まで立て直したら、ランダムに戻ります。
始める基準とやめる基準に差をつけているので、境目で接待のオン・オフがパタパタ切り替わることはありません。

自動プレイで計測した目安では、上手い人にはまったく発動せず、ふつうの腕前の人だとプレイ全体の3割ほど接待します（通常モードなら約150手でゲームオーバーになる腕前で、300手以上続くようになります）。

気づかれないよう、このモードでは接待AIのひとことは「○ミノが来ました。」だけになり、ミノ査定も表示しません。
今こっそり接待しているかは、ブラウザの開発者ツールで `settai.state().assisting` を見ると確認できます。
基準の数値は `engine.js` の `NATURAL_ASSIST` で変えられます。

### 鬼Lv1〜Lv3

毎回いちばん困るミノを出すと攻略不可能なので、お情けで手加減しています。ミノ査定の順位ごとに出る確率を決めていて、レベルで違います。

| 査定の順位 | 7位（最悪） | 6位 | 5位 | 4位 | 3位 | 2位 | 1位（最善） | NEXT |
|---|---|---|---|---|---|---|---|---|
| 鬼Lv1 | 35% | 26% | 18% | 11% | 6% | 3% | 0.7% | あり |
| 鬼Lv2 | 33% | 33% | 33% | 0% | 0% | 0% | 0% | あり |
| 鬼Lv3 | 33% | 33% | 33% | 0% | 0% | 0% | 0% | なし |

NEXT ありのときは、次のミノまで先に決めて盤面右上に予告します。
鬼は「今のミノを一番良い場所に置いた後の盤面」で困るミノを選ぶので、違う場所に置けば読みを外せます。
鬼Lv3 は NEXT を教えない代わりに、実際に置いた盤面を見てから困るミノを選ぶので、読みを外す余地がありません。

自動プレイで比べた目安（消せたライン数の平均。どの鬼も最後は必ずゲームオーバーになります）:

| | 上手い人 | ふつうの腕前 |
|---|---|---|
| 通常 | 118（300手でも終わらない） | 32 |
| 鬼Lv1 | 62 | 18 |
| 鬼Lv2 | 38 | 13 |
| 鬼Lv3 | 15 | 6 |
| 参考：手加減なし（毎回最悪・NEXT なし） | 4 | 2 |

確率は `engine.js` の `ONI_LEVELS`（`weights` に7位から順の重み、`next` に NEXT 予告の有無）で変えられます。

## 音

音声ファイルは使わず、すべて Web Audio API でその場で合成しています（`audio.js`）。

- BGM はロシア民謡「コロブチカ」（パブリックドメイン）をこのゲーム用に編曲したもの（メロディ・ベース・ドラム）
- 普段はイ短調。接待しているとき（接待モード、ナチュラル接待でこっそり接待している間）は、同じ曲をイ長調にして明るく鳴らします。曲の途中でも次の音から切り替わります
- レベルが上がるとテンポアップ、積み上がってピンチになるとさらに加速、鬼モードでは荒い音色になります
- 効果音：移動・回転・ドロップ・固定・ライン消去（消した数で変化、テトリスはファンファーレ付き）・レベルアップ・おすすめ位置に合ったとき・一時停止・ゲームオーバー

## ファイル

```
index.html   画面
style.css    見た目
engine.js    ゲーム本体と接待AI（画面や音に依存しない）
app.js       描画・入力・演出・タイトル画面のAIデモ
audio.js     BGM・効果音
test/        engine.js のテスト
```

`index.html` を直接開いても動くよう、ES Modules（`import`）は使わず、通常の `<script>` タグで読み込んでいます。

## 接待AIのしくみ（`engine.js`）

1. 7種類のミノそれぞれについて、「回転して横に動かして落とす」で置ける全パターンを試す
2. 置いた後の盤面を Dellacherie の評価関数（積む高さ・消したライン・穴・凸凹・井戸の深さ）で採点
3. さらに「次にも一番都合の良いミノを出す」前提で2手先まで読み、合計点が最も高いミノを出す
4. そのままだと I と O ばかり（テトリス量産）になるので、直近10個に出たミノは1回につき少し減点して種類をばらけさせる

親フォルダのデスクトップ版（Go + walk）と同じアルゴリズムで、同じ盤面には同じ評価・同じ置き場所を返します。
